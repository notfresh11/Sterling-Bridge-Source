# Sterling Bridge - Source Preview

This directory contains a copy of the Sterling Bridge production sources, provided
solely so users can inspect how the mod works and assess its behavior.

You may install and use Sterling Bridge as intended for personal use. Server
operators may install and run it on servers they own or administer. This permission
does not authorize modifying, reproducing, or redistributing the source code, or
creating derivative works from it. The source is provided for inspection, not as a
grant of source-code reuse rights.

Gradle scripts, the Gradle wrapper, and other build files are not included.

Source inspection is provided to support independent review; it is not a guarantee
that the mod is safe or suitable for every environment.
